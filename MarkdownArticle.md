# PowerShell and System Administration

## Introduction

PowerShell is a powerful command-line shell and scripting language used for system administration and automation.

This article demonstrates different **Markdown syntax** learned during the course.

---

## What is PowerShell?

PowerShell can be used to perform many system administration tasks.

Some examples include:

* Managing users
* Managing computers
* Managing files
* Managing Active Directory
* Automating administrative tasks

### Common PowerShell Commands

1. `Get-Process`
2. `Get-Service`
3. `Get-ADUser`
4. `Get-ADOrganizationalUnit`

---

## Advantages of PowerShell

**PowerShell** helps administrators automate repetitive tasks.

It can be used with:

* Windows Server
* Active Directory
* Excel
* Git
* GitHub

---

## Example PowerShell Code

```powershell
Get-Process
```

Another example:

```powershell
Get-Service
``

## Markdown Table

| Command                    | Purpose                                        |
| -------------------------- | ---------------------------------------------- |
| `Get-Process`              | Displays running processes                     |
| `Get-Service`              | Displays services                              |
| `Get-ADUser`               | Displays Active Directory users                |
| `Get-ADOrganizationalUnit` | Displays Active Directory organizational units |
